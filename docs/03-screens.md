# 3. 주요 화면 목록

## 워크스페이스

앱의 기본 화면이다. 여러 패널이 떠 있는 HTS형 작업 공간이며, 사용자는 이 화면에서 대부분의 작업을 수행한다.

주요 기능:

- 상단 시장 요약 바
- 여러 업무 패널 동시 표시
- 패널 드래그 이동
- 패널 최소화
- 패널 앞으로 가져오기
- 레이아웃 초기화

## 관심종목 패널

사용자가 추적하는 종목 목록을 표시한다. MVP에서는 데모 데이터로 현재가와 등락률을 보여준다.

향후 확장:

- 종목 검색
- 관심그룹 관리
- 실시간 현재가 반영
- 정렬 및 필터
- 종목 클릭 시 차트/호가/주문 패널 동기화

## 차트 패널

선택 종목의 가격 흐름을 표시한다. MVP에서는 CSS 기반의 간단한 캔들 형태를 사용한다.

향후 확장:

- 차트 라이브러리 도입
- 분봉/일봉/주봉 전환
- 거래량 표시
- 이동평균선, RSI, MACD 등 보조지표
- 십자선, 줌, 스크롤

## 호가 패널

매도/매수 호가와 잔량을 표시한다. MVP에서는 데모 호가 데이터를 사용한다.

향후 확장:

- 실시간 호가 수신
- 호가 클릭 시 주문 가격 자동 입력
- 잔량 막대 시각화
- 체결 강도 표시

## 주문 패널

종목, 수량, 가격, 매수/매도 버튼을 제공한다. MVP에서는 실제 주문을 보내지 않는다.

향후 확장:

- 시장가/지정가/조건부 주문
- 주문 전 확인 모달
- 주문 가능 금액 검증
- 주문 결과 알림
- 주문 실패 사유 표시

## 뉴스 패널

시장 관련 뉴스를 목록으로 보여준다. MVP에서는 데모 문구를 사용한다.

향후 확장:

- 뉴스 API 연동
- 종목별 뉴스 필터
- 중요 뉴스 알림
- 뉴스 클릭 시 상세 보기

## 계좌/잔고 패널

총평가, 평가손익, 주문 가능 금액을 표시한다. MVP에서는 데모 데이터를 사용한다.

향후 확장:

- 보유종목 목록
- 실현손익/평가손익 구분
- 예수금/증거금 상세
- 주문 체결 내역 연결
